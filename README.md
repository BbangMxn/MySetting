# MySetting

![Cat wearing a witch hat](assets/witch-cat.png)

A library of the Codex settings and skills I use. Update the list below when adding a skill.

## Agent settings

[AGENTS.md](AGENTS.md) defines my default communication style and coding principles. It references the `caveman` and `ponytail` skills.

## Skills

| Skill | Purpose |
| --- | --- |
| [aside](skills/aside/SKILL.md) | Work with Aside comments in Obsidian |
| [caveman](skills/caveman/SKILL.md) | Keep responses concise |
| [codegraph](skills/codegraph/SKILL.md) | Explore code structure and call relationships |
| [frontend-design](skills/frontend-design/SKILL.md) | Design frontend interfaces |
| [ponytail](skills/ponytail/SKILL.md) | Solve coding problems with minimal code |
| [rtk](skills/rtk/SKILL.md) | Manage command output and token use |

## Installation

1. Copy the skill folders you need into `~/.codex/skills/`.
2. Copy [AGENTS.md](AGENTS.md) to `~/.codex/AGENTS.md`, or merge it with your existing file.
3. If you use `AGENTS.md`, install both `caveman` and `ponytail`.

Check each `SKILL.md` for its requirements and usage conditions.
